# 打印 / 另存 PDF

中后台的高频真实需求：把表格或报表**打印出来**或**另存为 PDF**。

本库在 `tokens.css` 里提供了一块 `@media print`，只做「最小可用」的三件事 ——
不试图把组件库变成报表引擎。

## 自动做了什么

| 行为 | 为什么 |
| --- | --- |
| **强制白底黑字** | 打印在纸上，深底等于浪费墨且不可读。即使当前是 `data-theme="dark"` 也会变白底 |
| **缩放归位 `--vcl-scale: 1`** | 屏幕上的视口等比缩放在纸上没有意义 |
| **隐藏交互壳层** | 侧栏 / 顶栏 / 折叠按钮 / 遮罩层不打印 |
| **表格去斑马纹与阴影** | 纸上看不清浅底，保留行线作为分隔 |
| **表头跨页重复** | `thead { display: table-header-group }`，长表格每页都带表头 |
| **行不跨页断开** | `tr { break-inside: avoid }` |
| **卡片/面板去阴影加细边框** | 避免纸上一圈灰边 |
| **正文链接追加 URL** | `.vcl-prose a[href^='http']::after`，纸面可追溯 |

## 宿主需要做的

### 1. 给不该打印的元素加 `.vcl-print-hide`

```vue
<DataTableToolbar class="vcl-print-hide" />
<div class="vcl-print-hide">分页器 / 操作按钮 / 筛选条</div>
```

库只隐藏**自己的壳层**（`AppLayout` 的侧栏/顶栏）。工具栏、分页器、操作列这些是
**宿主组装**的，库不知道哪些该打印，所以要你自己标。

### 2. 需要打印全量数据时，自己取全量

**分页表格只打印当前页。** 这是刻意的：

- 展开全量行会让长表格打印失控（几百页）
- 需要库内绕过虚拟滚动与分页切片，代价与收益不成比例

要打全量，请宿主**用全量数据另渲染一个表格**（或临时把 `pageSize` 调到足够大再打印）。

## 明确不支持的（边界）

| 场景 | 现状 | 替代方案 |
| --- | --- | --- |
| **图表打印** | ❌ ECharts 是 canvas，打印时可能空白或截断 | 用 `ChartTable`（同一份数据渲染成表格），或宿主导出位图 |
| **地图打印** | ❌ amap 是第三方 SDK 的 canvas 图层 | 截图后贴入打印版 |
| **全量分页展开** | ❌ 只打当前页 | 见上「需要打印全量数据时」 |
| **打印分页控制** | ❌ 不提供 `break-before` 之类的编排 API | 宿主用 CSS 自行控制 |

::: warning 不做「自动把图表转位图」
那需要时序配合（等 canvas 绘制完成再触发打印），在库内做**不可靠** ——
`window.print()` 是同步阻塞的，等不到异步绘制。宁可明确说"不支持"，也不给一个时好时坏的实现。
:::

## 怎么验证它真的生效

`tests/e2e/print-media.spec.ts` 用 Playwright 的 `emulateMedia({ media: 'print' })` 做**真实渲染断言**
（不是读源码正则）：

```bash
npx playwright test tests/e2e/print-media.spec.ts
```

覆盖 6 条：缩放归位、暗色下强制白底黑字、阴影/模糊清零、`.vcl-print-hide` 隐藏、
链接追加 URL、表格表头重复 + 行不断开 + 斑马纹去除。

**负向对照**：把 `@media print` 改成 `@media print-disabled`（等价停用）→ 6 条全红；
复原 → 全绿。这证明测试真的在验证渲染结果，而不是"文件里有这几行字"。

## 已知的实现坑（留给后来者）

- **`--vcl-scale: 1` 必须 `!important`**：不加时 Playwright 实测仍取到屏幕值 `0.8333`。
- **表格类名是 `.data-table` 不是 `.vcl-data-table`**：本库只有 `--vcl-*` **令牌**加前缀，
  **CSS 类名没有统一前缀**（各域各自命名）。按前缀猜会静默失效。
- **demo 路由是 `#/<key>`**（如 `#/data-table`），不是 `#/components/<key>`。
