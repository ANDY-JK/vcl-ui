### 交互状态一致性评分

**B（良好）**

- Button/Input/Select/Drawer/Popover 的 hover/focus/active/disabled 状态统一使用 `--transition-fast` 和 CSS 变量
- `:focus-visible` 在 AppLayout 工具栏按钮、Group switch 中有覆盖
- **不足**：route-planner 组件的 hover/active 状态使用硬编码色值，与全局设计系统不一致

### 尺寸协调性

| 组件 | size='sm' 高度 | size='md' 高度 | size='lg' 高度 |
| :--- | :--- | :--- | :--- |
| Button | `clamp(30px, 5vw, 32px)` | `var(--ctrl-height)` ≈ 38-42px | `calc(--ctrl-height + 6px)` ≈ 44-48px |
| Input (stepper) | 30px | `var(--ctrl-height)` ≈ 38-42px | 46px |
| Select | — | `var(--ctrl-height)` ≈ 42-48px | — |
| Group (switch) | `clamp(28px, 4vw, 32px)` | `clamp(40px, 6vw, 44px)` | — |

**评价**：尺寸体系通过 `--ctrl-height` 变量实现统一，但 Select 的 trigger-wrapper 高度 `clamp(42px, 7vw, 48px)` 比 Input 的 `clamp(42px, 7vw, 48px)` 一致。Button sm 尺寸 30-32px 与 Input sm 尺寸 30px 协调。

### 暗色模式支持

**通过 CSS 变量实现，支持三种模式：**
1. `data-theme="dark"` 手动切换
2. `prefers-color-scheme: dark` 自动跟随系统
3. `useTheme()` composable JS 控制

**问题**：AppLayout 顶栏/底栏使用固定暗色（侧边栏配色），不跟随暗色模式切换——这是设计意图（顶栏始终暗色），但 route-planner 组件的 fallback 色值在暗色模式下会产生视觉异常。
