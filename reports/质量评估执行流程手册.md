### 阶段 5：动态响应式布局审计（核心专项）

**目标**：扫描硬编码 px，检查容器自适应、缩放、断点覆盖。

**执行命令**：

```bash
# 5.1 扫描所有硬编码 px（排除 tokens.css）
# PowerShell:
Get-ChildItem -Path src\components -Recurse -Include *.vue,*.css -Exclude tokens.css |
  Select-String -Pattern '\b\d+px\b' |
  Where-Object { $_.Line -notmatch 'clamp\(' -and $_.Line -notmatch 'var\(' } |
  Measure-Object

# 5.2 按文件统计硬编码 px 数量
Get-ChildItem -Path src\components -Recurse -Include *.vue |
  Select-String -Pattern '\b\d+px\b' |
  Group-Object Path |
  Sort-Object Count -Descending |
  Select-Object -First 10

# 5.3 检查 @container 查询
grep -rn "@container" src/components/

# 5.4 检查 @media 断点覆盖
grep -rn "@media.*max-width\|@media.*min-width" src/components/ --include="*.vue" --include="*.css"

# 5.5 检查 aspect-ratio 使用
grep -rn "aspect-ratio" src/components/ --include="*.vue"
```

**记录格式**：

```
- 相对单位覆盖率: X%（目标 ≥ 95%）
- 纯硬编码 px: X 处
- var/clamp 中合法 px: X 处
- @container 查询: X 处
- @media 断点: X 处（mobile X / tablet X / desktop X）
- 父容器自适应测试: 200px → 1200px
- 浏览器缩放测试: 100% → 200%
```

**当前结果（2026-08-18）**：
- 相对单位覆盖率: **65%**（❌ 未达标）
- 纯硬编码 px: **925 处**
- var/clamp 中合法 px: **536 处**
- @container 查询: **0 处**（❌）
- @media 断点: **6 处**（mobile 5 / tablet 0 / desktop 0）
- 父容器自适应: ⚠️ AppLayout 顶栏 200px 溢出
- 浏览器缩放: ❌ 150% 部分溢出，200% 布局错位

### 4.3 自动化集成建议

```yaml
# .github/workflows/quality-assessment.yml
name: Component Library Quality Assessment
on:
  schedule:
    - cron: '0 2 * * 1'  # 每周一凌晨 2 点
  workflow_dispatch:
jobs:
  assess:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '18'
      - run: npm ci
      - run: npm run typecheck
      - run: npm run lint
      - run: npm run test:unit
      - run: npm run build
      - run: npm run report:coverage
      - uses: actions/upload-artifact@v4
        with:
          name: quality-report
          path: reports/
```

## 八、Commit Message 规范

```
<type>(<scope>): <subject>

<body>

Refs: #<issue-id>
Docs-Update: <是否涉及文档变更>
Visual-Change: <是否涉及视觉变更>
```

**type 枚举**：
- `fix` - 缺陷修复
- `perf` - 性能优化
- `style` - 视觉/样式调整（含动态响应式）
- `docs` - 文档更新
- `refactor` - 重构
- `chore` - 构建/工具链
- `test` - 测试补充

**示例**：

```
fix(Select): 添加搜索 debounce 防止大数据量卡顿

Refs: #P1-006
Docs-Update: 否
Visual-Change: 否
```
