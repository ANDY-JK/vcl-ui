## §2 basic 模块

### Button.vue（175 行）
**功能**：5 种 variant（primary/secondary/outline/danger/ghost）、3 档 size（clamp 弹性高度，移动端 ≥44px 触控）、loading（禁用+CSS spinner+`aria-busy`）、icon、block 通栏、showArrow；支持 `--ctrl-*` token 覆写。
**API**：props `text/variant/size/icon/disabled/loading/block/showArrow`；emits `click`；slot default。
**审查发现**：
- `Button.vue:44` aria-label 直接用图标原始名（如 "loader"），读屏读出英文 id，未走 i18n
- `Button.vue:4-11` 每实例挂 onErrorCaptured 属过度设计，`return false` 会阻断上层 ErrorBoundary
- `Button.vue:113,141` primary/danger 文本色硬编码 `white`，暗色主题不可覆写
- 不支持 `nativeType="submit"` / href 链接变体

### IconSvg.vue（103 行）
**功能**：双 provider 图标核心——lucide（@lucide/vue 静态全量）+ solar（@iconify/vue，235KB 数据按需异步）；kebab→Pascal 自动转换；未命中/加载中渲染四宫格兜底 SVG。
**API**：props `type(必填)/size(xs~xl)/color/provider`；无 emits/slots。
**审查发现**：
- `IconSvg.vue:63` 渲染函数内 `ensureSolarIcons().then()` 无 `.catch` → unhandled rejection，失败后每次重渲染重试
- `IconSvg.vue:78-90` lucide 名未命中静默渲染兜底图，warnOnce 存在却未用，拼写错误难排查
- `IconSvg.vue:12` `toPascal` 对空段（`foo--bar`）会抛 TypeError

### Tag.vue（270 行）
**功能**：标签+徽标合一。内联标签（6 色 variant、sm/md、药丸、圆点、closable）；角标 sup 模式（count 数字上限 99+、自定义 color、offset、showZero、hidden、纯红点），`role="status"` + `--color-badge-ring` 描边。
**API**：props `text/variant/size/closable/rounded/dot/max/count/color/offset/showZero/hidden/sup`；emits `close`；slot default。
**审查发现**：关闭按钮无 aria-label（`Tag.vue:127`）；dot 角标 aria-label 硬编码中文'提示'（`Tag.vue:115`）；isSupMode 条件下传 slot 即进 sup 模式与 prop 名不一致（`Tag.vue:54-58`）。

## §3 nav 模块

### Breadcrumb.vue（82 行）
**功能**：items 数组（label+path/to），自动识别 RouterLink（`#/`、`/` 开头）vs 原生 a vs 当前页纯文本；自定义 separator；`aria-current="page"`；可换行。
**审查发现**：`Breadcrumb.vue:42` 只检查 `path`，只传 `to` 且非路由格式时被静默渲染为纯文本丢链接；索引作 key；最后一项为链接时缺 `aria-current`。

### Menu.vue（424 行）
**功能**：多级菜单。vertical（点击展开）/horizontal（hover 浮层）双模式；collapsed 折叠态（只显图标+hover 浮层）；multiple 控制子菜单多开；light/dark；divided 分隔项；递归无限层级；disabled；键盘 Enter/Space/方向键/Escape。
**审查发现**：
- `Menu.vue:39-40` enterTimer/leaveTimer 卸载不清理，pending 定时器写已卸载 ref
- `Menu.vue:153-182` ARIA 硬伤：`ul[role=menu]` 与 `div[role=menuitem]` 之间隔裸 `li`（应加 `role="none"`）；方向键不能进出子菜单
- `Menu.vue:141-149` 子级 opacity 最低 0.5 与禁用 0.4 叠加，禁用项几乎不可见；overlay 子菜单无焦点陷阱

### Pagination.vue（188 行）
**功能**：v-model 页码、省略号折叠（±2）、快速跳页（Enter 提交+钳制）、i18n 总条数、`calcTotalPages` 防 Infinity。
**审查发现**：`Pagination.vue:61/66/89` aria-label 硬编码中文（总数文案却走 i18n，标准不一）；省略号是 disabled button 未加 `aria-hidden`；modelValue 越界无法自愈；无 pageSize 切换器。

### Steps.vue（181 行）
**功能**：horizontal/vertical、current、done/active/pending 三态（完成打勾）、desc、clickable（role=button+Enter/Space）。
**审查发现**：`Steps.vue:46-48` 活动步骤缺 `aria-current="step"`；current 越界无钳制警告；clickable 无法禁用单步。

### Tabs.vue（185 行）
**功能**：4 变体 underline/pills/card/tabbar（仅 tabbar 支持 icon）；WAI-ARIA 键盘（ArrowLeft/Right 循环+Home/End+切换后聚焦）。
**审查发现**：`Tabs.vue:70` `aria-controls="tabpanel-xxx"` 悬空引用（组件内无对应面板）；仅自动激活模式；tab 多时无横向滚动处理。

## §4 layout 模块

### AppLayout.vue（878 行）
**功能**：应用级骨架。桌面侧边栏（AccordionNav+logo+折叠按钮 72px）、移动端抽屉（<768px+遮罩）、终端风 topbar（hamburger、`~/分类/标题` 面包屑、topbar-tools 插槽+预设工具类、用户区/登出）、content-body（内嵌 ErrorBoundary+RouterView）、bottombar（上/下一组件导航+可拖拽滚动进度条+百分比）。断点自动折叠：768-1024 折叠、≥1024 展开。滚动进度用 MutationObserver+scroll 双通道+节流。
**API**：props `navItems/logoText/username`；emits `logout`；slots `topbar-tools/topbar-right`；provide `isMobile/toggleSidebar/toggleCollapse`。
**审查发现**：
- `AppLayout.vue:291` 整个 style 块**未 scoped**，十余个通用类名全局泄漏
- `AppLayout.vue:79-83` `router.afterEach` 注册后不注销，卸载后仍执行（泄漏）
- 进度条仅鼠标拖拽无 touch/pointer；断点硬编码不可配；移动抽屉无焦点陷阱/Esc

### ModalBox.vue（455 行）
**功能**：5 种 modalType——default（纯 slot）/confirm（委托 ConfirmModal）/form（取消+提交）/detail（label-value 明细）/select（单多选列表）；4 档 size；焦点陷阱+焦点恢复、弹窗互斥（registerModal+mutexScope）、Esc 关闭、遮罩防误关（mousedown+mouseup 双确认）、`--z-modal`。
**API**：props `visible/title/modalType/size/closable/maskClosable/zIndex/internal/mutexScope/confirm*/detailItems/selectItems/selectValue/selectMultiple`；emits `update:visible/confirm/cancel/form-submit/select-confirm/close`；slots default/footer。
**审查发现**：`ModalBox.vue:177-186` confirmVariant 把 info/success 都映射 primary 且非法值返回 undefined；select 模式选项按钮无 `aria-checked`；confirm 模式下 `close` 事件语义丢失。

### MiniLayout.vue（440 行）
**功能**：移动端/小程序模板。底部 TabBar（4 tab+中央凸起扫码）、扫码类型 sheet（Teleport+焦点陷阱+Esc，本库 a11y 修复点）、子页面返回头（history 兜底）、假搜索框、safe-area 适配、i18n 全覆盖。
**审查发现**：tabs/scanTypes/颜色全部硬编码（`MiniLayout.vue:28-41`），本质是演示页模板非通用组件；`#/button` 硬编码 hash 链接；假搜索框 readonly 无 aria 说明。

## §20 富文本专项（2026-08-30 同日执行完毕，最后一个挂起项清零）

**方案选型：原生 composition 感知受控 contenteditable（零新依赖）**——引编辑器（TipTap 等）= 新依赖违背依赖纪律；beforeinput 全自绘成本过高；execCommand 打补丁不解决 IME。混合策略：合成事件解耦修 IME + execCommand 保留给工具栏格式化命令（已废弃但全量实现，warnOnce 防护在位）+ 粘贴时序消毒。

根因（v-html 反模式）：`@input` emit → modelValue 变 → `v-html` 重设 innerHTML → IME 合成中 DOM 被清。每敲一个拼音候选即被打断。

| 1 | **移除 v-html 响应式绑定**，DOM 回写收敛为唯一 watch 入口：外部赋值（值 ≠ 上次 emit）才重设 innerHTML；自身 emit 的回声不回写（保光标与合成文本） | FormRenderer.vue |
| 2 | **IME 合成保护**：compositionstart/compositionend 感知，合成期间 input 不 emit，合成结束一次性同步 | FormRenderer.vue |
| 3 | **写入收敛**：`richtextSyncFromDom()` 为唯一出口（input/compositionend/execCommand/粘贴共用），消毒后 emit | FormRenderer.vue |
| 4 | **粘贴时序消毒**：paste preventDefault → text/html 过 sanitizeHTML → 光标处 Range 插入（兜底 beforeend）。原 v-html 轮回承担的"粘贴内容被净化"职责改由插入前承担（原实现实际在插入后才消毒，事件属性早已可触发——本修复为净提升） | FormRenderer.vue |
| 5 | 死代码清理：richtextExec ref（只写不读）删除；richtextContent 改只读 computed | FormRenderer.vue |
