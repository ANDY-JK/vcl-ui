## 一、数据展示

### 1.1 DataTable 数据表格

**功能：** 智能数据表格，支持列配置、排序、筛选、分页、行操作、列设置、全屏、截图、缩放、滚动进度、本地存储。组件采用 Composable 架构，将功能拆分为 15+ 个 composable 模块（`useTableCore`、`useTableFilter`、`useTableEdit`、`useTableFullscreen`、`useTableScreenshot`、`useTableZoom`、`useTableScrollProgress`、`useTablePersistence` 等），是整个组件库中最复杂的组件。

**路径：** `components/data/DataTable.vue` + `components/data/composables/`

**Props：**

| Prop | 类型 | 默认 | 说明 |
|------|------|------|------|
| `columns` | `Column[]` | — | 列配置 |
| `data` | `Record<string,any>[]` | — | 表格数据 |
| `rowKey` | `string` | `'id'` | 行唯一标识字段 |
| `storageKey` | `string` | — | 本地存储键（列宽/排序/筛选持久化） |
| `height` | `string` | — | 表格高度 |

**Events：** `row-click` · `row-dblclick` · `selection-change` · `sort-change` · `filter-change` · `page-change`

**Composable 架构：**

| 模块 | 功能 |
|------|------|
| `useTableCore` | 核心数据管理、排序、分页 |
| `useTableColumns` | 列管理、列宽拖拽、列设置 |
| `useTableFilter` | 列筛选、全局搜索 |
| `useTableEdit` | 单元格编辑 |
| `useTableEvents` | 行/单元格事件 |
| `useTableExtras` | 行操作、上下文菜单 |
| `useTableFullscreen` | 全屏模式 |
| `useTableScreenshot` | 表格截图导出 |
| `useTableZoom` | 表格缩放 |
| `useTableScrollProgress` | 滚动进度条 |
| `useTablePersistence` | 列宽/排序/筛选持久化 |
| `useTableTooltip` | 单元格 Tooltip |
| `useTableCellMenu` | 单元格右键菜单 |
| `useTableColSettings` | 列设置面板 |

**示例：**
```vue
<DataTable :columns="cols" :data="rows" row-key="id" storage-key="my-table" />
```

**评估：**

| 维度 | 评分 | 说明 |
|------|------|------|
| 代码质量 | ⭐⭐⭐⭐ | Composable 拆分清晰，职责单一；但 15+ 个 composable 间的依赖关系复杂，新开发者上手成本高 |
| 布局策略 | ⭐⭐⭐⭐ | 使用 `clamp()` 响应式缩放，适配多端；全局 CSS + scoped CSS 双层样式管理 |
| 功能完备性 | ⭐⭐⭐⭐⭐ | 功能极其丰富：排序/筛选/编辑/全屏/截图/缩放/持久化/上下文菜单，远超一般表格组件 |
| 交互体验 | ⭐⭐⭐⭐ | 行/列操作完整，支持键盘导航；列宽拖拽、列设置面板细节到位 |
| 性能负载 | ⭐⭐⭐ | 大数据量时 DOM 节点数可能爆炸（无虚拟滚动），万行数据需外部分页 |
| 通用性 | ⭐⭐⭐⭐ | 支持自定义列渲染、行操作、上下文菜单，覆盖大多数 CRUD 场景 |

**优化建议：**
1. ⚠️ **性能**：增加虚拟滚动支持（`virtual-scroll` prop），当数据量超过 500 行时自动启用，仅渲染可视区域行
2. ⚠️ **类型安全**：Column 类型定义中 `formatter`/`render` 函数签名应统一为泛型，避免 `Record<string, any>` 泛滥
3. ⚠️ **文档**：15+ 个 composable 的 API 缺少文档，建议补充 composable 级别的 JSDoc
4. **通用性**：增加 `summary`（合计行）支持，`export`（CSV/Excel 导出）内置支持

### 1.2 Card 卡片

**功能：** 通用卡片容器，支持两种模式：`grid`（标题+内容+底部操作区）和 `stat`（统计卡片，含图标、数值、标签、趋势）。合并了原 Card 和 StatCard 的功能。

**路径：** `components/data/Card.vue`

**Props：**

| Prop | 类型 | 默认 | 说明 |
|------|------|------|------|
| `type` | `'grid' \| 'stat'` | `'grid'` | 卡片模式 |
| `title` | `string` | — | 卡片标题（grid 模式） |
| `highlight` | `boolean` | `false` | 高亮边框 |
| `summary` | `boolean` | `false` | 汇总样式（浅色背景） |
| `overflowVisible` | `boolean` | `false` | 允许内容溢出（下拉/弹出场景） |
| `value` | `string \| number` | — | 统计值（stat 模式） |
| `label` | `string` | — | 统计标签（stat 模式） |
| `icon` | `string` | `'circle-alert'` | 统计图标（stat 模式） |
| `color` | `string` | — | 自定义图标色（stat 模式） |
| `trend` | `number \| string` | — | 趋势百分比（stat 模式，正数↑绿色/负数↓红色） |

**Slots：** `default`（内容） · `header`（自定义头部） · `footer`（底部操作区）

**Events：** `click`（stat 模式点击）

**示例：**
```vue
<!-- grid 模式 -->
<Card title="用户信息" :shadow="true">
  <p>姓名：张三</p>
  <template #footer><Button text="编辑" size="sm" /></template>
</Card>

<!-- stat 模式 -->
<Card type="stat" value="1,284" label="今日订单" icon="shopping-bag" :trend="12.5" color="#6366F1" />
```

**评估：**

| 维度 | 评分 | 说明 |
|------|------|------|
| 代码质量 | ⭐⭐⭐⭐⭐ | 代码简洁，交集类型设计巧妙，两种模式 IDE 自动补全良好 |
| 布局策略 | ⭐⭐⭐⭐ | clamp() 响应式，stat 模式 flex 布局合理 |
| 功能完备性 | ⭐⭐⭐⭐ | grid + stat 双模式覆盖卡片场景；缺少 `shadow` prop（文档有但代码用 hover 阴影替代） |
| 交互体验 | ⭐⭐⭐⭐ | stat 模式 hover 上浮效果，highlight 高亮边框 |
| 性能负载 | ⭐⭐⭐⭐⭐ | 轻量组件，无性能负担 |
| 通用性 | ⭐⭐⭐⭐ | overflowVisible 专为内嵌下拉/弹出场景设计，实用 |

**优化建议：**
1. **文档一致性**：文档中提到 `bordered` 和 `shadow` props，但实际代码中没有这两个 prop — 应修正文档或补充 prop
2. **通用性**：stat 模式增加 `trendLabel`（趋势文字自定义）和 `trendIcon`（自定义趋势图标）

### 1.3 ToggleList 开关列表

**功能：** 可切换的列表项，支持 `switch`（开关按钮）和 `button`（操作按钮）两种模式。专为「发快递」等业务场景设计。

**路径：** `components/data/ToggleList.vue`

**Props：**

| Prop | 类型 | 默认 | 说明 |
|------|------|------|------|
| `items` | `Record<string,any>[]` | — | 列表数据 |
| `idKey` | `string` | `'id'` | ID 字段 |
| `titleField` | `string` | `'display_name'` | 标题字段 |
| `descriptionField` | `string` | `'description'` | 描述字段 |
| `iconField` | `string` | `'icon'` | 图标字段 |
| `toggleField` | `string` | `'is_enabled'` | 开关字段 |
| `extraColumns` | `ExtraColumn[]` | `[]` | 额外列 |
| `disabled` | `boolean` | `false` | 禁用 |
| `isLoading` | `boolean` | `false` | 加载中 |
| `emptyText` | `string` | `'暂无数据'` | 空文案 |
| `variant` | `'switch' \| 'button'` | `'switch'` | 模式 |
| `buttonLabel` | `string` | `'发快递'` | 按钮模式文字 |
| `phoneField` | `string` | `'phone'` | 手机号字段 |

**Events：** `toggle` · `itemClick` · `buttonClick`

**评估：**

| 维度 | 评分 | 说明 |
|------|------|------|
| 代码质量 | ⭐⭐⭐⭐ | 逻辑清晰，字段映射灵活 |
| 布局策略 | ⭐⭐⭐⭐ | clamp() 响应式，icon+content+extras+action flex 布局 |
| 功能完备性 | ⭐⭐⭐ | switch/button 双模式够用；缺少搜索/筛选能力 |
| 交互体验 | ⭐⭐⭐⭐ | loading/empty 状态完整，hover 反馈 |
| 性能负载 | ⭐⭐⭐⭐⭐ | 轻量，v-for 渲染 |
| 通用性 | ⭐⭐⭐ | `buttonLabel` 默认值 `'发快递'` 过于业务耦合，建议改为 `'操作'` |

**优化建议：**
1. ⚠️ **通用性**：`buttonLabel` 默认值从 `'发快递'` 改为 `'操作'`，降低业务耦合
2. **功能**：增加 `searchable` prop 支持列表内搜索
3. **无障碍**：switch 模式的 `@click.stop` 阻止了事件冒泡，但缺少 `aria-label` 描述当前开关状态

### 1.4 Collapse 折叠面板

**功能：** 可折叠/展开的内容面板，支持 v-model 双向绑定，完整的 WAI-ARIA 无障碍支持（`aria-expanded`、`aria-controls`、`aria-labelledby`）。

**路径：** `components/data/Collapse.vue`

**Props：**

| Prop | 类型 | 默认 | 说明 |
|------|------|------|------|
| `title` | `string` | — | 面板标题（必填） |
| `open` | `boolean` | `false` | 是否展开（支持 v-model） |
| `disabled` | `boolean` | `false` | 是否禁用 |
| `id` | `string` | — | 面板唯一标识（用于 aria 关联，不传则自动生成） |

**Events：** `update:open`

**示例：**
```vue
<Collapse title="详细信息" v-model:open="isOpen">
  <p>折叠内容</p>
</Collapse>
```

**评估：**

| 维度 | 评分 | 说明 |
|------|------|------|
| 代码质量 | ⭐⭐⭐⭐⭐ | 代码极简，aria 关联设计优秀 |
| 布局策略 | ⭐⭐⭐⭐ | clamp() 响应式，max-height 过渡动画 |
| 功能完备性 | ⭐⭐⭐ | 单面板折叠功能完整；缺少手风琴模式（accordion 互斥） |
| 交互体验 | ⭐⭐⭐⭐ | chevron 旋转动画，border 色变化 |
| 性能负载 | ⭐⭐⭐⭐⭐ | 轻量 |
| 通用性 | ⭐⭐⭐ | 缺少 accordion 模式限制了多面板场景 |

**优化建议：**
1. **功能**：增加 `accordion` prop（手风琴互斥模式），需要外层 CollapseGroup 组件管理
2. **功能**：增加 `defaultOpen` prop（初始展开，不触发 v-model 更新）
3. ⚠️ **动画**：`max-height: 1000px` 硬编码上限，内容超高时动画可能不完整 — 改为 `max-height: none` + JS 计算实际高度

### 1.5 Tree 树形

**功能：** 树形数据展示，支持展开/折叠、选中、勾选（含父子联动+半选状态）、懒加载。使用 `provide/inject` 管理树状态，递归渲染（最大深度 15 防栈溢出）。集成 `useTreeFlatten` composable 管理展开状态。

**路径：** `components/data/Tree.vue`

**Props：**

| Prop | 类型 | 默认 | 说明 |
|------|------|------|------|
| `data` | `TreeNode[]` | — | 树数据 |
| `level` | `number` | `0` | 递归层级（内部使用） |
| `checkable` | `boolean` | `false` | 是否可勾选 |
| `defaultExpandedKeys` | `(string\|number)[]` | `[]` | 默认展开的 key |
| `expandAll` | `boolean` | `false` | 默认展开全部 |
| `selectable` | `boolean` | `false` | 是否可选中 |
| `selectedKey` | `string\|number\|null` | `null` | 选中 key（支持 v-model） |

**TreeNode 类型：**
```typescript
interface TreeNode {
  key: string | number
  label: string
  children?: TreeNode[]
  disabled?: boolean
  checked?: boolean
  icon?: string
}
```

**Events：** `node-click` · `check-change` · `update:selectedKey`

**评估：**

| 维度 | 评分 | 说明 |
|------|------|------|
| 代码质量 | ⭐⭐⭐⭐ | provide/inject 架构合理，useTreeFlatten 复用好；但 `findParent` 每次递归遍历全树，O(n²) 复杂度 |
| 布局策略 | ⭐⭐⭐⭐ | 层级深度系统（字号×0.85^level、透明度递减）视觉层次好 |
| 功能完备性 | ⭐⭐⭐⭐ | 展开/折叠/选中/勾选/半选/父子联动功能完整 |
| 交互体验 | ⭐⭐⭐⭐ | Transition 动画，选中左侧色条，展开箭头右指→下转 |
| 性能负载 | ⭐⭐⭐ | `findParent` 递归 O(n²)，大树（1000+ 节点）勾选性能差 |
| 通用性 | ⭐⭐⭐⭐ | TreeNode 接口通用，key/label/children/disabled/checked/icon 标准 |

**优化建议：**
1. ⚠️ **性能**：构建 `key → parent` Map（O(n) 一次遍历），替代每次 `findParent` 递归，大树勾选从 O(n²) 降至 O(n)
2. **功能**：增加 `lazy` prop + `load` event 支持懒加载子节点
3. **功能**：增加 `draggable` prop 支持拖拽排序节点
4. **无障碍**：`tabindex` 逻辑较复杂，建议简化为首项 tabindex=0，其余 tabindex=-1，由 ArrowUp/Down 导航

### 1.6 Image 图片（含头像 + 全屏预览）

此导航项包含三个组件：**Image**（图片展示）、**Avatar**（头像）、**ImagePreview**（全屏预览）。三者独立使用，按场景选择。

#### Image 图片

**功能：** 图片展示组件，支持懒加载（IntersectionObserver，环境降级处理）、加载占位、加载失败兜底、点击灯箱预览。包含 `#ifndef MP_WEIXIN` 条件编译支持微信小程序。

**路径：** `components/data/Image.vue`

**Props：**

| Prop | 类型 | 默认 | 说明 |
|------|------|------|------|
| `src` | `string` | — | 图片地址 |
| `alt` | `string` | `''` | 替代文本 |
| `width` | `number` | — | 宽度（px） |
| `height` | `number` | — | 高度（px） |
| `size` | `number` | `80` | 默认宽高（width/height 未设时） |
| `fit` | `'cover' \| 'contain' \| 'fill' \| 'none' \| 'scale-down'` | `'cover'` | object-fit |
| `radius` | `number` | `4` | 圆角（px） |
| `round` | `boolean` | `false` | 圆形 |
| `lazy` | `boolean` | `true` | 懒加载（IntersectionObserver） |
| `preview` | `boolean` | `true` | 点击灯箱预览 |
| `loadingText` | `string` | `''` | 加载中文案 |
| `errorText` | `string` | `''` | 失败文案 |

**Events：** `load` · `error` · `click`

**示例：**
```vue
<Image src="photo.jpg" :size="120" :preview="true" round alt="头像" />
```

#### Avatar 头像

**功能：** 头像组件，图片加载失败时回退为姓名首字母文字头像。支持 4 档尺寸和 2 种形状。

**路径：** `components/data/Avatar.vue`

**Props：**

| Prop | 类型 | 默认 | 说明 |
|------|------|------|------|
| `src` | `string` | — | 头像图片地址 |
| `name` | `string` | — | 姓名（失败时取首字母） |
| `size` | `'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | 尺寸（32/40/56/72px） |
| `shape` | `'circle' \| 'rounded'` | `'circle'` | 形状 |

**示例：**
```vue
<Avatar src="user.jpg" name="张三" size="lg" shape="circle" />
```

#### ImagePreview 全屏预览

**功能：** 全屏图片预览，功能极其丰富：
- 缩放（滚轮/按钮/双击/双指 pinch）
- 拖拽平移（鼠标/触摸）
- 旋转（90° 递增）
- 水平翻转
- **Canvas 标注系统**（矩形/圆形/画笔，6 色/3 线宽，选中拖动、删除、键盘快捷键 R/P/C/Esc/Delete）
- 多图切换（缩略图面板、左右箭头、触摸轻扫）
- 导出合成图（原图+标注 → 下载/复制到剪贴板，跨域 CORS 处理）
- 移动端适配（缩略图横排、色点按空间裁减、触摸手势全支持）

**路径：** `components/data/ImagePreview.vue`

**Props：**

| Prop | 类型 | 默认 | 说明 |
|------|------|------|------|
| `src` | `string \| ImageItem \| (string \| ImageItem)[]` | — | 图片源（单图/多图，自动归一化） |
| `initialIndex` | `number` | `0` | 多图初始索引 |
| `title` | `string` | — | 标题 |

**ImageItem 类型：**
```typescript
interface ImageItem { url: string; label?: string }
```
