## 快速开始

### 安装

```bash
npm install
```

### 全量导入

```ts
// main.ts
import { createApp } from 'vue'
import App from './App.vue'

// 全量导入组件库
import { i18n, setLocale } from '@/components/index'

const app = createApp(App)
app.use(i18n)
setLocale('zh-CN') // 可选，默认中文

app.mount('#app')
```

### 按需导入

```ts
import { Button, Input, DataTable } from '@/components/index'
```

### 基本使用

```vue
<template>
  <Button variant="primary" @click="handleClick">点击我</Button>
  <Input v-model="text" label="用户名" placeholder="请输入" />
</template>

<script setup>
import { ref } from 'vue'
import { Button, Input } from '@/components/index'

const text = ref('')
const handleClick = () => alert('clicked')
</script>
```

## 基础组件

### Button 按钮

多变体按钮，支持图标、加载态、块级宽度。

#### Props

| 参数 | 说明 | 类型 | 默认值 |
|------|------|------|--------|
| text | 按钮文字 | `string` | — |
| variant | 颜色变体 | `'primary' \| 'secondary' \| 'outline' \| 'danger' \| 'ghost'` | `'primary'` |
| size | 尺寸 | `'sm' \| 'md' \| 'lg'` | `'md'` |
| icon | 图标名 | `string` | — |
| disabled | 禁用 | `boolean` | `false` |
| loading | 加载中 | `boolean` | `false` |
| block | 块级宽度 | `boolean` | `false` |
| showArrow | 显示箭头 | `boolean` | `false` |

#### Events

| 事件 | 说明 | 参数 |
|------|------|------|
| click | 点击 | `(e: MouseEvent)` |

#### 使用示例

```vue
<Button variant="primary" text="提交" @click="submit" />
<Button variant="danger" text="删除" :loading="deleting" />
<Button variant="outline" size="sm" icon="plus" text="新增" block />
```

### IconSvg 图标

SVG 图标组件，支持 Solar 和 Lucide 双图标源。

#### Props

通过 `type` 属性指定图标名称，`size` 属性指定尺寸（`'sm' | 'md' | 'lg'` 或数字）。

```vue
<IconSvg type="circle-alert" size="md" />
<IconSvg type="x" :size="24" />
```

---

### Tag 标签徽标

标签 + 徽标二合一组件，支持内联模式和角标模式。

#### Props

| 参数 | 说明 | 类型 | 默认值 |
|------|------|------|--------|
| text | 文字内容 | `string` | — |
| variant | 颜色变体 | `'default' \| 'primary' \| 'success' \| 'danger' \| 'warning' \| 'info'` | `'default'` |
| size | 尺寸 | `'sm' \| 'md'` | `'md'` |
| closable | 可关闭 | `boolean` | `false` |
| rounded | 圆角药丸 | `boolean` | `false` |
| dot | 圆点模式 | `boolean` | `false` |
| max | 数字溢出上限 | `number` | — |
| count | 数字徽标 | `number` | — |
| color | 自定义背景色 | `string` | — |
| offset | 角标偏移 | `[number, number]` | — |
| showZero | count=0 时仍显示 | `boolean` | `false` |
| hidden | 强制隐藏 | `boolean` | `false` |
| sup | 角标模式（包裹内容时右上角定位） | `boolean` | `false` |

#### Events

| 事件 | 说明 | 参数 |
|------|------|------|
| close | 关闭 | — |

#### 使用示例

```vue
<!-- 内联标签 -->
<Tag text="在线" variant="success" rounded />

<!-- 角标徽标 -->
<Tag sup :count="5" :max="99">
  <IconSvg type="bell" />
</Tag>

<!-- 圆点状态 -->
<Tag dot variant="danger" />
```

## 存储模块

### 轻量 API（localStorage）

同步 API，带 TTL 支持。

```ts
import { storageSet, storageGet, storageDelete, storageHas } from '@/components/index'

storageSet('key', 'value', 60000) // TTL 60s
const val = storageGet('key')
storageHas('key')
storageDelete('key')
```

### 重量 API（IndexedDB）

异步 API，支持 TTL、动态 store、批量事务。

```ts
import { dbPut, dbGet, dbDelete, dbHas, dbGetAll, dbKeys, dbCount, dbClear, dbBatch } from '@/components/index'

await dbPut('store', 'key', value)
const val = await dbGet('store', 'key')
await dbDelete('store', 'key')
```

### 合同收集存储适配层

本地 IndexedDB + 云端 Supabase 双后端。

```ts
import { createBackend, validateStorageConfig } from '@/components/index'

const backend = createBackend(config)
```

import { useTheme } from '@/components/index'

| getSystemTheme | 系统偏好 | `() => 'light' \| 'dark'` |
