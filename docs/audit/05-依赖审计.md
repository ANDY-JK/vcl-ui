### 3.2 关键问题：`xlsx` 用 GitHub tarball 直连

```json
"xlsx": "https://cdn.sheetjs.com/xlsx-0.20.3/xlsx-0.20.3.tgz"
```

- **供应链风险**：不从 npm registry 安装，改用 CDN tarball，锁定的 URL 若 CDN 变更/失效将无法安装；
- **版本管理**：0.20.3 是 sheetjs 官方社区版，npm 上已无新版（官方迁移到自家 CDN），这是业界常见做法，但需在文档中说明来源与校验方式；
- **体积**：xlsx 是主包体积膨胀的主因（单 chunk 758 kB）。

### 3.3 peer 依赖声明

```json
"peerDependencies": {
  "echarts": "^5.0.0 || ^6.0.0",
  "pinia": "^2.1.7",
  "vue": "^3.4.0",
  "vue-router": "^4.3.0"
}
```

- peer 声明合理，但 `pinia` 实际**只在 devDependencies**，且审计未见组件强依赖 Pinia（`store.ts` 用自研 localStorage 实现）——需确认 Pinia 是否真的被使用，若未用可从 peer 移除，避免误导消费者。
- `echarts-wordcloud` 在 dependencies 而 `echarts` 在 peer，二者需要运行时对齐，消费者易踩「版本不匹配」坑，建议文档注明兼容组合。
