# 01 · 执行摘要

> 面向决策者与管理者的 5 分钟速读。完整证据见对应专项报告。

## 一、审计对象

- **项目**：`vue-component-lib` v1.0.0，Vue 3 通用组件库
- **规模**：61 个组件 + 185 个 TS/工具文件 = 246 个源文件，约 6.4 万行
- **组件域**：basic / data / form / feedback / nav / layout / chart / login / storage / amap / route-planner / form-builder / wc，共 14 域
- **技术栈**：Vue 3.4 + TypeScript 5.4 + Vite 5 + vue-i18n + ECharts + Pinia

## 二、综合健康度

**58 / 100（C+）** —— 可构建、类型安全，但测试清零、存在发布阻断级安全问题。

各维度评分见 `README.md` 一页速览表。

## 三、问题清单（按优先级）

### 🔴 P0 —— 发布阻断（必须修复后才能对外发布）

| # | 问题 | 证据 | 影响 | 建议 |
|---|------|------|------|------|
| P0-1 | **单元测试被全部删除** | `git status` 显示 5 个 `tests/unit/*.spec.ts` 被删（Button/Drawer/Input/Select/Toast），`vitest run` 报 "No test files found" 退出码 1，覆盖率 0% | 失去回归保护，任何改动无法验证 | 从 git 历史恢复 `tests/unit/`，或重建核心组件测试 |
| P0-2 | **CI 流水线被删除** | `.github/workflows/ci.yml` 状态为 `D`（deleted） | 无自动化质量门禁 | 恢复 CI，加入 typecheck+lint+test+build |
| P0-3 | **Git 提交钩子被删除** | `.husky/pre-commit` 状态为 `D`（deleted） | 本地质量门禁失效 | 恢复 husky + lint-staged 配置 |
| P0-4 | **富文本 `v-html` 未消毒（XSS）** | `form-builder/FormRenderer.vue:413` `v-html="richtextContent"` 直接渲染用户可编辑的富文本，无任何消毒 | 存储型 XSS，攻击者可注入脚本 | 引入 DOMPurify 消毒后再渲染；DataTable 已用 `sanitizeHTML` 是正例 |
| P0-5 | **联动表达式动态 eval** | `form-builder/useFormLinkage.ts:84,97,108` 三处 `new Function` 对含用户输入的表达式求值 | 代码注入风险 | 改用安全表达式解析器（如 jsep）或严格白名单校验 |

### 🟠 P1 —— 高危（应尽快处理）

| # | 问题 | 证据 | 建议 |
|---|------|------|------|
| P1-1 | **直接依赖存在已知漏洞** | `npm audit`：`vue-i18n`（XSS，moderate）、`echarts`（XSS，moderate）、`echarts-wordcloud`、`vite`（路径穿越，high，dev） | 升级 `vue-i18n` ≥ 9.14.5、`echarts` ≥ 6.1.0、`vite` ≥ 6.4.3 |
| P1-2 | **表单标签不关联控件** | `form/Input.vue:489,523,563`、`form/Select.vue:839` 浮动 label 为兄弟节点，无 `for`/`id` | 改用 `<label :for>` + input id，或 `aria-labelledby` |

## 四、做得好的地方（保持）

1. **类型安全**：`vue-tsc` 全库零错误，61 组件全部 TypeScript。
2. **内部基建**：`_internal/` 下 `useFocusTrap`、`useClickOutside`、`useModalManager`、`warnOnce`、`z-top` 等工具成熟，复用价值高。
3. **API 设计**：`amap-key.ts` 密钥统一管理、`sanitize.ts` 白名单消毒、存储层 localStorage/IndexedDB 双后端抽象，都是正例。
4. **导出规范**：`src/components/index.ts` 导出清晰，`Space` 已标记 `@deprecated`，类型导出齐全。
5. **a11y 局部达标**：Drawer/ModalBox 焦点陷阱、Select combobox、Menu/Tabs/Steps/Pagination 的 ARIA 骨架实现规范。

```
第 3 周：P1-3 拆包 → P1-5 键盘可达性
第 4 周起：P2 系列按组件域滚动处理
```
