## 1. 盘点（2026-09-30 实测，`src/components` 全量）

| 类别 | 命中数 | 性质 |
|---|---|---|
| `left:` / `right:`（绝对/固定定位） | 88 / 57 | **人工逐处裁决**：跟随文本起始侧的（关闭钮、浮层锚定）转 inset-inline；固定物理角（地图角标、全屏钮）保持物理 |
| `margin-left:` / `margin-right:` | 37 / 6 | 机械转 `margin-inline-start/end` |
| `padding-left:` / `padding-right:` | 10 / 2 | 机械转 `padding-inline-start/end` |
| `border-left:` / `border-right:` | 10 / 4 | 机械转 `border-inline-start/end` |
| `text-align:`（left/right） | 18（含 center） | left/right 转 `start/end`，center 不动 |
| `translateX(` / `translate(-` | 16 / 13 | **人工裁决**：轮播/画布拖拽偏移是物理量保持；菜单展开、进度指针类转 `translate(±100% * inline 方向)` 或逻辑方案 |
| 垂直向（margin/padding/border 的 top/bottom） | ≈253 | **免改**——RTL 只影响水平流向 |
| `border-radius` 四角写法 | 分散于上述文件 | 跟随所在盒的流向裁决 |

## 2. 验证基建（先于任何样式改动）

1. `evidence-viewports` / `audit-viewports` 扩展 `?dir=rtl`（或 `html[dir='rtl']` 注入）模式：
   取证路由 ×2 方向，复用既有「零横向溢出 / 零元素越界」断言。
2. 代表路由集（覆盖四类裁决）：DataTable（滚动/列宽）、Select（浮层锚定）、Menu（缩进/箭头）、
   Drawer（滑出方向）、Tabs（指示条）、Pagination（首末页按钮）。
3. e2e 增加一条 `rtl-smoke.spec.ts`：上述路由在 `dir=rtl` 下 axe 扫描 + 关键控件几何断言
   （Select 面板与触发器起始边对齐、Drawer 从 inline-end 滑出）。

## 3. 分期

- **P1 表单/导航/反馈域**：机械类全转 + 裁决类逐处过 → RTL 取证全绿为止。
- **P2 数据展示域**：DataTable/Tree/Collapse（列宽计算与滚动含 JS 侧方向量，需读 `getComputedStyle` 的方向值）。
- **P3 明示不做**：chart（ECharts 内部物理坐标系）、amap（地图 SDK）、wc 域（Shadow DOM 样式注入由宿主负责）。
- 全部完成后撤掉 README 的「RTL 硬边界」声明，并按组件在文档标注支持矩阵。

## 4. 依赖与风险

- `translateX` 的 JS 侧计算（浮层定位 useFloating、轮播）需同步改——这是本项唯一的非 CSS 工作量来源。
- `dir` 属性继承自宿主 `<html dir>`，库内组件**不自行设置** `dir`（跟随文档流向），README 写明该契约。
- 估工：P1 ≈ 1 天（含取证基建），P2 ≈ 1 天，全部验证复跑 ≈ 0.5 天。
